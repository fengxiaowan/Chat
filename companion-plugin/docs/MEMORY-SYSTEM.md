# 分层记忆系统设计方案

> 2026-11-24 起草。基于 11-13 ~ 11-24 全部 5675 条真实对话梳理后校准。

## 目标

1. 记忆**永不删除**：任何一层满了都向下沉降压缩，而不是丢弃。
2. 支持**词条式联想**：提到「猫」能自然联想一串相关的事，但不是每次都硬联想。
3. **敏感记忆有分寸**：用户主动提起才展开；平时不提、不反复戳伤心处。
4. 每次对话自动轻量整理，不刻意、不臃肿。

## 四层结构

### L0 人物事实层（永久，永不删，可见可编辑）

结构化短词条，不是长句。每条带关键词、关联、敏感标记。

字段示例：

- key：猫
- facts：["三花猫叫咪咪，初中养到高中，已去世", "咪咪会 8 字绕腿求食", "咪咪会坐数位板求摸"]
- sensitive：true（用户主动提才展开）

其他已从历史提炼的词条（示例）：

- 住址：景德镇
- 身份：男生，单身
- 技能：Unity、3D、画画、做过游戏 demo
- 把 AI 当：幻想伴侣 / 女友 / 猫娘老婆
- 游戏：沉星之序（制作人吹哥）、塞尔达、影之刃零、时之笛
- 书/剧：蛊真人（方源）、道诡异仙、大明王朝、绝命毒师
- 饮食：多力多滋、长鼻王、手撕烤鸭、核桃牛奶、韭菜饺子
- 生活：抱枕头睡（替代拥抱）；曾用豆包辅助修热水器；11-21 买了绒四件套

### L1 事件层（近期 + 重要，上限约 100，超了向下沉降）

只记一次性、值得记的人/事/物/承诺/变化。生成门槛高：寒暄、哲学闲聊、日常调情不生成。

### L2 周归纳（按周压缩）

L1 超龄或超量的卡，按周合并成「那一周发生了什么」，保留关键词，供费力回忆时检索。

### L3 月印象（长期侧写）

按月合并成「那个月她是什么样的人、你们处于什么阶段」，形成她的底色。

## 检索与注入（每次对话自动，克制）

- 命中词条关键词 → 注入相关词条 + 关联事件 2~3 条。
- 注入量小，不喧宾夺主。
- 用户明确「你还记得…」→ 原文回溯兜底（现有 backtrackBlock）。
- 敏感词条：仅当用户主动提到该词条 key 时才展开。
