# 闲聊

一个微信式的日常闲聊页面。打开后直接说话就行，不需要配置任何 Key —— 它用的是你当前 DSH 账号里的模型。

## 打开

安装这个插件后，在浏览器里打开：

```
<当前 DSH 地址>/chat
```

例如 `http://127.0.0.1:49672/chat`。建议单独开一个标签页，甚至拖到浏览器书签栏。

## 它做了什么

- **一句一条**：回复会按句子切成几个气泡发出来，像微信一样；不会一次甩给你一整段。
- **打字节奏**：每条之间有停顿，「正在输入」偶尔会消失一下再出现；你发新消息，它会立刻停下当前的回复。
- **短**：单条气泡超过 38 个字会被切断，一轮最多 4 条，输出上限也压得很低。
- **自己记**：每轮聊完，它会用同一套模型在后台整理一次记忆，分成「关于对方 / TA 说过的习惯 / 你们之间 / 你自己」四类。这些是聊出来的，不需要你填表。
- **会守你的线**：你说过「别叫我宝」「少问点问题」这类明确要求，会记进「TA 说过的习惯」并一直遵守。

## 数据在哪

对话和记忆都只存在你浏览器的 localStorage 里，键名以 `companion.` 开头。换浏览器或清缓存会丢。设置面板里可以看到它记住了什么，也可以清空。

## 已知限制

- 记忆是每次聊完追加整理一次的，不是逐句精算；聊得越多越准，但也会记岔。
- 图片、语音还没做，现在只处理文字。
- 一轮里它不会主动先开口；主动打招呼需要另外的定时能力。
