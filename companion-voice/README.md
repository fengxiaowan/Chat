# 小喵 · 桌面语音（通话模式）

在打游戏、看视频时也能跟小喵说话，不用切回网页。
屏幕上不会出现任何悬浮球，只在**系统托盘**有个小图标。

## 怎么用

1. 双击 `start.vbs`（无黑窗后台启动）
2. 托盘出现一个小圆点图标（右下角托盘区）
3. **右键托盘图标** → 「开启语音功能」
4. 按 `Ctrl + F1`（或右键菜单点「进入通话模式」）
5. 说「**老婆**」，她开始听你说
6. 说完自动识别、回复、用网页里同一个声音念出来
7. 再按 `Ctrl + F1` 退出通话模式，麦克风关闭

## 托盘菜单

| 菜单项 | 作用 |
|---|---|
| 开启 / 关闭语音功能 | 总开关。关闭时**语音引擎进程直接退出**，麦克风和内存全部释放 |
| 通话模式（Ctrl+F1） | 在总开关打开时才可用 |
| 打开聊天网页 | 打开 `127.0.0.1:8899/liao` |
| 退出 | 结束全部语音相关进程 |

双击托盘图标 = 快速切换通话模式。

## 状态怎么看

托盘图标的鼠标悬停提示会显示当前状态：

- 通话模式关闭
- 待命，等你说「老婆」
- 正在听你说的
- 她在想
- 她正在说

## 为什么要先按热键

如果一直开着麦克风听唤醒词，看视频、听歌时会被剧里的台词误唤醒。
所以默认完全不监听，只有你主动按一下 `Ctrl+F1` 才开，10 分钟没用会自动关掉。

## 文件说明

| 文件 | 作用 |
|---|---|
| `start.vbs` | 一键启动（状态球 + 热键 + 语音服务） |
| `voice-presence.mjs` | 主服务：监听 → 识别 → 聊天 → 朗读 |
| `tray.ps1` | 托盘菜单 + 全局热键 Ctrl+F1（不会再显示悬浮球） |
| `test-*.mjs` | 自动化验证脚本（不需要麦克风） |

> `status-orb.ps1` / `hotkey.ps1` 是早期版本，已被 `tray.ps1` 取代，可以删掉。

## API 用哪个

统一走你聊天页那套，跟着 `swapkey.bat` 走：

- 聊天：`/liao/chat` → 读 `companion-standalone/config.local.json`（swapkey 写的就是它）
- 声音：`/liao/tts` → 和网页自动连读同一个 edge-tts 声音

换 key 后只需重新跑一次 `swapkey.bat`，语音这边自动生效，不用改任何东西。

## 运行数据

都在 `%TEMP%\xiaomiao-voice\` 下：

- `state.json` — 当前状态（给圆点读）
- `presence.log` — 运行日志
- `hotkey.signal` — 热键信号

## 已知限制

- 唤醒词和识别用的是本地小模型，**识别精度一般**。例如「老婆」偶尔被听成「宝宝」「好吧」。
  唤醒词匹配是独立的，所以通常仍能正常触发，只是识别出来的文字会有偏差。
- 语音引擎把「图零零」硬编码成了热词和名字纠错，偶尔会把识别结果里的字改成「图零零」。
  服务里做了清洗，会把它去掉。
- 网络（模型中转）不稳时，她会回一句「刚才网络抖了一下」，这是上游问题，不是语音链路的问题。

## 退出

任务管理器里结束这几个进程即可：

- `too-voice.exe`
- `node.exe`（命令行含 `voice-presence`）
- `powershell.exe`（命令行含 `status-orb` 或 `hotkey`）
